Project Details

In-depth descriptions of major projects and code.

NOIVA — White Cane Improvement for Visually Impaired People

Co-founded with Saanvi R. NOIVA enhances mobility by addressing limitations of traditional canes: it detects head-level hazards, moving objects, gaps/cracks, and crowds. Our system combines AI-powered cameras for object detection, GPS navigation with turn-by-turn guidance delivered through a connected vibration wristband, and predictive safety features. We're currently training the object detection pipeline and will develop global GPS-integrated navigation patterns (different vibration patterns for "go straight", "turn left", "turn right", "stop", "off-route"). This project aims to provide navigation features not currently available globally.

Current focus: object detection model and embedded system prototyping.

Microbial Fuel Cell (MFC) — Science Fair (with Helen Qiu)

We use anaerobic digester residue from water treatment plants to generate electricity, prioritizing low-cost, widely available feedstock over expensive cultures. I built sensors and a data logger to stream voltage, pH, and temperature to a web dashboard. We will integrate AI to predict environmental conditions that maximize output.

Role: technical lead — sensors, data logging, web dashboard, and AI modeling; Helen leads biological experiments.

Inventory Algorithm — MIT BWSI Project

Led a subgroup to build an algorithm that predicts next month's inventory for small businesses using simple Python structures so teammates with varying coding experience could participate. The algorithm helps nonprofits and small stores manage stock levels.
